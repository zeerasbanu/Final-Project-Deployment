# BlogSpace – Full Stack Blog Application

## Project Description

BlogSpace is a full-stack blogging web application developed as part of the Codomax Full Stack Web Development Internship 2026.

The application allows users to register, log in, create blog posts, read stories, update existing blogs, and delete their own posts.

## Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Database Library:** Mongoose
- **Authentication:** Express Session, bcryptjs
- **Deployment:** Render (planned)

## Features

1. User registration and login
2. Session-based authentication
3. User dashboard and profile
4. Create, Read, Update, and Delete blogs
5. Save drafts and publish stories
6. Search blogs by keywords
7. Filter blogs by categories
8. View individual blog details
9. Responsive web design
10. User logout functionality

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder in VS Code.
3. Install dependencies:

   `npm install`

4. Create a `.env` file and configure:

   `MONGODB_URI=your_mongodb_connection_string`

   `SESSION_SECRET=your_random_session_secret`

5. Start the server:

   `npm start`

6. Open the application:

   `http://localhost:3000`

## CRUD Operations

| Operation | Description |
|---|---|
| Create | Users can create and publish new blogs |
| Read | Users can view published blogs |
| Update | Users can edit their own blogs |
| Delete | Users can delete their own blogs |
